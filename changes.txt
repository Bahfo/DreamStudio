MAJOR CHANGES AND UPDATES TO DREAMSTUDIO AND THE FUTURE OF DEVELOPMENT

The DreamStudio Team: 
    Please read the following carefully as it affects the future of 
    DreamStudio development. Any changes from now on will follow the same
    structure described in the following file.

MAJOR UPDATE AND THE FUTURE OF THE SOFTWARE: 
Firstly, we should say that the framework we are working with to develop 
DreamStudio is no longer sufficient for the big needs and requirements we
are looking for. The Library (IronKinter) and its parent framework 
(customtkinter/tkinter) does not have all the needs required to continue
developing a strong, efficient, and reliable IDE for big projects.

What does that mean to you?
Starting from Version 1.0.1 BETA, the framework that DreamStudio will start
using is PyQT/PySide, this will affect you majorly, as the previous version 
will not be compatable to be updated at all. Thus, any older versions of 
DreamStudio will be deprecated and no longer supported. However, any later
version than 1.0.1 BETA will be updated based on V1.0.1, meaning that it will
become the standard production software baseline from now on.

This will not affect you too much hopefully, as the same structure and 
backend will stay the same, any projects you created before will be reserved 
as it is since it is created logically as a folder on your Operating System. 
However, any other preferences you made (which are for now extremely low) will
be lost.

How the new structure will be made?

From the next update, DreamStudio will be called DreamJetPack, it will contain 
multiple Software Development Kits for Developers. We will apologize as the 
next version will be delayed until an unknown time for now (about five months). 
However, once released, it will contain the following kits:
1. DreamStudio; as your main Integrated Development Environment.
2. MetaStudio; which will take the older code of DreamStudio V1.0.0, and will be
   developed in a completely different way compatable with IronKinter. This new
   studio will be developed for General Higher Automation Tasks (Such bash or
   powershell tasks, Python Artifical Intellgence Tasks, and More...)
3. NeoruxJS; the machine learning library standardized with JavaScript. 
4. IronKinter; we will leave the scope of IronKinter for developing DreamStudio, 
   but we will develop the framework on the long run to be completely standard for
   later usages. 

Why we are changing from IronKinter to PyQT?
Because we need to develop the studio faster without writing everything we need 
from scratch, although it will be higherly great if we have IronKinter as the 
framework for developing DreamStudio. We unfortunately have to ship the features
required fast and with reliance on a powerful C++ backed. This is achieved greatly
with PyQT/PySide. Thus we made this change.

Another thing you will find in this repository from now on is the webpages for 
DreamStudio and DreamJetPack. Named as 'dreamstudio_web'.

We highly want you to tell us your opinions and feelings about this change.

The DreamStudio Team.
