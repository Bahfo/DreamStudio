# Ether A.I: Your Personal Offline A.I Assistant with Softdream IDE

Ether A.I is a model trained specifically to work side-by-side with the programmer on large codebases. It does not interact with your work, it respects you, and suggests you changes to make your codebase better and more professional. 

Ether A.I is a coding-agent model that is built to be an apprentice assistant programming agent that suggest you changes, helps you finding bugs faster, and let's you modify bad code structures to make it more readable, syntax-presistant, and even better.
