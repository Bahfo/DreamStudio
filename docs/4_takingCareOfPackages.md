# Taking Care of Packages

DreamStudio offers out-of-the-box ways to view and configure all packages for your programming languages inside your project.

- Open Solution Explorer from left sidebar. 
- Navigate to `Packages`. 
- You can see it has multiple sections for each programming language, Python, D-lang, and B-Sharp. 
- You can download, remove, and manage all packages for each language separately. 
- In addition, you can view info about each package and any available docs for it.
