# Initializing a Project

To initialize a project, you must open-up DreamStudio first.

Once you open DreamStudio for the first time or after a reload, it welcomes you into a project manager window. 

- Click `New Project` to start a new project.
- Select the project type, and the main programming language (Note: This will not affect features available for any other language within the project, so a Python project still can access D-lang features). 
- Name your project and choose the desired path. 
- Click `Create` and wait until configuration is done.
