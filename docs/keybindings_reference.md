### Keybindings Reference

This article covers the main keybindings in DreamStudio:

*Tabs Navigation*
1. Opening the left side bar: Ctrl + Tab + B
2. Navigating through opened studio tabs: Shift + Tab
3. Opening a new tab: Ctrl + Tab + N
4. Closing a tab: Ctrl + Tab + W
5. Opening EtherAI Screen: Ctrl + Tab + E
6. Move Tab location to left: Ctrl + Tab + Left arrow
7. Move Tab locaiton to right: Ctrl + Tab + Right arrow

*Editor Management and Navigation*
1. Cut line: Ctrl + X
2. Copy line: Ctrl + C
3. Paste line: Ctrl + V
4. Undo action: Ctrl + Z
5. Redo action: Ctrl + Y
6. Select all: Ctrl + A
7. Find in file: Ctrl + F
8. Find and Replace: Ctrl + Shift + F
9. Open File: Ctrl + O
10. Save Session: Ctrl + S
11. Save all tabs: Ctrl + Shift + S
12. Scroll line up: Ctrl + Up Arrow
13. Scroll line down: Ctrl + Down Arrow
14. Comment/Uncomment Selection: Ctrl + /
15. Ctrl + I + Up Arrow: Increase indentation by one space
16. Ctrl + I + Down Arrow: Decrease indentation by one space
17. Increase font size: Ctrl + = 
18. Decrease font size: Ctrl + -
