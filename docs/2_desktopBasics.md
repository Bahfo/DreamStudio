# Desktop Basics

When you start DreamStudio, the dsektop appears in its default layout.

The desktop includes these areas: 
- Title bar and Options bar — Contain tools and utilities to set and manage your environment.
- Left and Right Panels — contain services that can be toggled to open and close, such as Solution Explorer, Source Control, and Project Properties.
- Main Window (Hero) — Open files in code editors and develop codes.
- Status bar — Contains file and project status in addition to quick-access tools.

When you want to edit or create a new file, you do so from either the options bar (the left options to open or create an empty file) or from the *Solution Explorer*. To save your work, simply press Ctrl+S or from the options bar.

## Solution Explorer
Contains a treeview of your project and its contents, you can access some utilities at the top of the explorer, or by right-clicking inside it to view a context menu containing file operations. 
The solution explorer also contains packages viewer to view the packages currently installed on your environment.

## Find and Replace
An utility that searches all files in your current working directory for words or phrases, with ability to replace it.

## Source Control
Manages your integration with Git and GitHub. 

## File Outline
Shows a treeview of all methods, classes, and objects created within the currently opened file. 

## Python Interpreter
A simple shell to write fast commands and scripts into a Python interpreter shell. It is connected in the background with a Jupyter kernel. 

## Terminals
A horziontal panel at the bottom that includes an integrated OS terminal, in addition to PromptX terminal.

## Code Editor 
The main part of the IDE that contains the integrated code editor to set up your projects and type your codes. Includes integrated features such as syntax highlighting, go-to-definitions, documentations, autocompletion, run and debug, and more.

## Properties Explorer
Shows current project and opened file properties.

## TODO Search
Searches and shows all TODOs configured in current codebase.
