# The Code Editor

DreamStudio relies on Ironica (its code editor engine) for manging opened files within the tab editor. 

Ironica is built on top QScintilla editor. It uses its keybindings and features to support editing files and viewing them. Ironica features syntax highlighting, autocompletion, documentation, go-to-definition, folding, imports counting, run and debug, custom run configurations, breakpoints handling, colors management, and many other useful utilties. 

It also comes with its right-click context menu as well with more utilities. 

Ironica supports many programming languages. DreamStudio gives the support for Python, D-lang, and B-Sharp, while Ironica offers extended syntax highlighting support for Bash, HTML, CSS, Powershell and CMD, in addition to many other DSLs.
