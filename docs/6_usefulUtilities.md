# Useful Utilties

DreamStudio also comes with other useful utitilies out of the box, here are the most important ones: 

1. Support for PromptX: PromptX is DreamStudio's custom scripting shell, it has its own style of typing commands and removes many boilerplates of other shell scripting languages by shortening long commands in, say Bash, with simple small scripted commands. 

2. Commands Window: To access quickly features and utilites within DreamStudio, you can use the commands window. You can open it from title bar, Tools menu, then click on `Commands Window`.

3. Ether-AI: The AI Agent built into DreamStudio, it has ability to view your files, give debugging support, modify in files, and generate feedback. 

4. Databases: DreamStudio also supports connections to external databases such as MySQL, PostgreSQL, MongoDB, and InfluxDB. 

5. Servers and SSH: In addition to all above, you can easily access external servers and their files using SSH utilities built into DreamStudio as well.
