# QSS Files For DreamStudio

This folder contains all `.qss` files for DreamStudio styles. 

### What You Are Going to Find
Mainly, you are going to find the following: 

1. Theme Files for IDE Main Window: These include the following: 
- `coffee_dark.qss`
- `coffee_light.qss`
- `dark_hc.qss`
- `dark.qss`
- `davy.qss`
- `light_hc.qss`
- `light.qss`
- `material_dark.qss`
- `material_light.qss`
- `monokai.qss`
- `moses.qss`
- `solarized_dark.qss`
- `solarized_light.qss`
- `tokyonight.qss`

2. Startup Window Theme Files: Including: 
- `startup_dark.qss`
- `startup_light.qss`
- `create_dialog.qss`
