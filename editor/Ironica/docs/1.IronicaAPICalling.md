## Downloading and Importing Ironica
To download, head towards the Official Ironica Repository, then download as a .zip file. Or you can use git cloning if you prefer terminal download. 

```bash
git clone https://github.com/Bahfo/Ironica
cd Ironica
```

### Importing Ironica
Importing is straight-forward. You use the built-in UI builder: 
```python
from Ironica import *
```
