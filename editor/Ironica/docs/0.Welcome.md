# Ironica: DreamStudio's Editor and Programming Languages Support Provider

Welcome to the official source code of *Ironica*, which is the engine providing support for programming languages. Ironica is built on top of **QScintilla**. Which is a **PyQt6** module that provides Graphical User Interfaces bundled in Python. 

Ironica adds the main utilities for languages support in addition to providing a basement built-in for some langauges. The design choice is left standard for a user if he wants to add a new language extension. Currently, Ironica supports the following programming languages support: 

- Python. 
- Bash and PowerShell.
- C and C++.
- Lua.

And as stated eariler. The system's engine is flexible enough to allow users to add any plugin to any other programming language they want. 

Within these documentation files, you will find helpful information for: 
1. Importing Ironica and using it inside your code files. 
2. The syntax and API provided by Ironica for adding a new language plugin.
3. How to link your plugin backend with Ironica layers and frontend.
