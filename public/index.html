The DreamStudio Project

The DreamStudio Project is EXcellent TechStacks Integrated Development Environment and the base environment for other editor-style applications.
Here you can find all info related to the project in addition to accessing the source code.

Documentations can be found on the official EXcellent TechStacks website.

If you want to contribute to DreamStudio, please head into contributing to DreamStudio to find out more on how you can contribute.


About DreamStudio

DreamStudio is an integrated development environment built and powered by PyQt6 engine to provide modern development experience for Python, C++,
and B-Sharp. It also serves as the foundation for other EXcellent TechStacks IDEs and editors.
