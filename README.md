# <h1 style="color: #158693ff;">DreamStudio IDE</h1>

DreamStudio IDEprovides comprehensive facilities to computer programmers for software development. It focuses on creating a modern, user-friendly environment designed to enhance coding efficiency and productivity. ## <h2 style="color: #4a93a4ff;">Introduction</h2>
For many years, DreamStudios has been working on their own integrated development environment (IDE) to solve programers issues with debugging, coding, and fast code generation using a helpful environment. The team thought of every single detail that interests programmers, from very the visual details, to main core environment debugging solutions. DreamStudio IDE is the pearl that came alive after working for years to fullfill the interests and requirements of developers, coders, hoppiests, as well as companies in coding and debugging.

### <h3 style="color: #6075a4ff;">DreamStudio IDE Is Not About Coding Only</h3>
You may notice, if you opened the software, that DreamStudio IDE is not about generating code or debugging code. It has tools for almost all programmers, developers, and even scientists. Programmers can benefit from its fast-to-produce code using EtherAI (the A.I tool that comes with DreamStudio IDE for free) or professional syntax highlighting tools. Developers and Debuggers have many strong and great options for fast and in-real-time debugging configuration tools. Both programmers and developers also have the option to use the built-in terminal (DayDream Terminal) with its strong capabilities and wild usages for performance, code debugging, complexity calculation tools, and more, or they can also use the file manager terminal for easy creating files and workspaces for their projects. Scientists and engineers can also use the built-in plotting, testing, and simulation tools for easy and fast simulation time compared to other tools. 

### <h3 style="color: #6075a4ff;">B# (B-Sharp) Comes For Free With The Environment</h3>
Once DreamStudio IDE is downloaded, B-Sharp is automatically added to user's path for easy and fast usage of the language, it also comes configured in the default built-in langauges configuration tools for fast usage. B-Sharp also comes in flavors here for variaty of usages (B-Sharp Scientific, B-Sharp Original, and B-Sharp for Editors)

## <h2 style="color: #4a93a4ff;">Features</h2>
DreamStudio IDE comes with many features and capabilities, here are some features:

### <h3 style="color: #6075a4ff;">For Vibe Coders</h3>
- Fast and easy methods to create, save, open, and close files with multiple tabs handling and fast-to-save methods alongside fast-to-open methods.
- All-Textbox-Tools are available (normally, as any IDE should)
- Specified syntax configuration tools that are easy to access, modify, delete, and save, with abilities to define your own custom syntax highlight and methods.
- The ability to add, configure, and save code snippets, add a built-in code block to your code easily and fast, define new code blocks, or delete code blocks you do not want (code blocks come in .cdblx extension).
- Code faster with EtherAI, an artificial intelligence tool built within the environment, comes for free, and makes coding 10x faster. If you do not want it to show, simply go to settings and turn off EtherAI.

### <h3 style="color: #6075a4ff;">For Debuggers and Code Watchers</h3>
- Solution Explorer, Toolbox, Workspace Manager, and Properties Window all allow you to edit and configure your solution or project very fast and easy, you can use also, to do that, the built-in tools inside DayDream Terminal which also (as it should be) comes for free built-in within the environment.
- Manage Resources easily, tasks, and use Container Window to manage your environment fast (supported for Windows and Linux only)
- Manage Databases easily with built-in tools for monitoring databases and the support of SQL. 
- Git and GitHub are easily accessed within the code editor and projects.
- Debugging Tools, and Debugging Platforms are easily accessed and supports all native languages installed within the environment, and most used languages. 
- You can verify code safety for your system using Verify Code Safety Tool.
- An easy method to compile your code into low-level langauges (assembly or related languages) using Compile Code tool.

### <h3 style="color: #6075a4ff;">For Engineers and Simulators</h3>
- Use variety of plotting tools for easy and fast rendering (also watches for system requirements and enhances simulation based on system and device capabilities)
- Graph Inspector lets you inspect and modify the graph code and graph simulation.
- You can also use the Graph Inspector Tool to easily simulate your animations and/or visuals.

### <h3 style="color: #6075a4ff;">For Beginners</h3>
![](icons\code_snippets\ide.png)

DreamStudio IDE comes in default with three main tabs: 

1. The upper tab is menus tab. Here, all tools (almost) lie, access them by clicking on the tab a tool lies inside.

2. The left frame controls three utilities: File management and settings (leftmost), "current workspace" (loading and refreshing settings), and "run and debug" options

3. The right frame controls tabs, number of lines withing a text file, and the main text editor. 

There is a tab in the bottom that shows some utilities: Warnings (shows number of warnings and where do they set), as well as Problems (number and location), Selecting and Debugging Configurations.
A status bar sets at the right of this frame showing the last successful option the user did, you can also access there the license agreement (clicking the version button) file manager, and the terminal that comes within your operating system. 

### <h3 style="color: #6075a4ff;">For Experts</h3>
![](icons\code_snippets\ide_dark.png)

The window above shows several options that come inside the (Tools) tab.

1. Manage solution and available toolboxes easily at the right.
2. Open Terminal, Command Window (for specified commands)
3. Manage Resources and Tasks easily
4. Contain your folders fast like a real file container, isolate them in a specific environment, and use related isolation commands.
5. Access, Manage, Edit, and Save Databases within your project's environment.
6. Use and access Git and GitHub easily (the right buttons).
