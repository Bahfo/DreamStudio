HOW TO MAKE YOUR OWN PROGRAMMING LANUGUAGE?
YOU NEED TO LEARN THE FOLLOWING LIBRARIES:

1. Regular Expressions: import re   # re: regex
   Which is useful for creating a Lexer or at least starting lexical analysis.
2. Parsing: import lark # Lark
   Handles complex grammar rules, with a very good documentation. It can convert
   tokens into a parse tree or AST.
3. Evaluation and Execution: There are multiple libraries here:
   A. operator: Maps symbols to functions. 
   B. math    : Provides complex mathematical functions.
   (Most interpreters at this stage are written manually, but some libraries like
   these do help as well). 
4. Debugging: graphviz which visualizes the AST. 
5. REPL and Console: cmd which builds a simple interactive shell for the language

THAT'S IT ALL
